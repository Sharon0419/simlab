# v0.7 任务成功点与评估

## 打开

双击原目录“启动SimLab.cmd”，仍使用深蓝色桌面界面。飞机新案例使用“打开飞机成功点案例.cmd”，或导入docs/cases/2026-09-08-aircraft-three-days/success-v0.7中的simproj。软件无需联网或启动服务器。

## 配置

“模型数据 → MissionType”选择任务类型。在下方分钟辅助输入填写总时长、出航、返航、起飞至成功点分钟，预览各阶段时刻后点击“应用到此任务类型”，再保存。也可直接编辑原字段：DURN小时，TFOUT/TFRET/MSUCPT为0～1比例；出航+返航比例不能超过1。分钟输入保存为上述原字段，不另存第二套值。

成功点只支持配置SimLabFlightRule的固定飞行任务。缺省MSUCPT=1，成功点在计划落地；0代表一旦实际起飞即成功，未起飞或取消不会成功。固定值守行为保持原样。

飞机案例使用DURN=3、TFOUT=TFRET=1/6、MSUCPT=5/6：09:00起飞，09:30进入任务区，11:30返航并达到成功点，12:00计划落地。11:00故障中止不成功；11:45故障中止已经成功但不完整完成。同刻到达成功点优先，11:30故障也算成功（用户于2026-09-11确认）。

## 查看和导出

- “结果分析 → 飞行与备用机”：NMREQ/NMSTA/NMSUC、FMSTA/FMSUC、请求/起飞/成功架次，以及独立的完整完成、中止、取消和时间统计。
- “任务成功率”：各波成功点、起飞率、成功率和完整完成率；分母均为计划请求任务数。
- “首轮成功判定”：首轮每任务实际成功时间、阶段、原因、成员；首轮事件中有“达到任务成功点”。
- “导出任务CSV”：各任务跨轮汇总，含阶段比例、成功比例及阶段架·小时。
- “逐轮飞行CSV”：全部重复试验的任务明细；1000轮×9任务=9000行，保留中止/落地、成功时间与成员，可独立复核。

成功与完整完成不是互斥分类。已成功任务仍可能中止；原有时间满足率不因成功比例修改而变化。请求、起飞、成功飞机数均为架次，不是去重机队规模。

## 兼容与边界

扩展格式升级5，读取旧1～4格式；保存/导出新格式后需要v0.7及以上版本。旧运行结果保留原样；没有成功指标时显示未计算并提示重跑，不从完整完成数反推成功数。

指标映射范围见METRIC_DICTIONARY.md；目前仅为固定全员编队子集，未获得原厂数值等价认证。STACC/MTACC等仍未冠以原厂名称。保障人员排队、部分编队、延迟起飞、阶段独立故障倍率不属于本版。
