# v0.7 实施契约

2026-09-11；基线 v0.6.0。实施依据：V0.7-PLAN.md。边界规则已由用户确认。

## 范围与语义

固定飞行任务使用原字段 MissionType.MSUCPT（0～1，默认1），成功点为 start + DURN × MSUCPT。固定值守不增加成功点语义，非默认值拒绝运行。

依据本机 SIMLOX 2017 手册第183、565～576页：达到成功点与完整完成独立；成功点之前中止的编队不成功，其成员也不成功。本版整队起飞、整队中止、空中无成员替换，因此成员成功数量等于成功编队的实际成员数量。MSUCPT=0仅已起飞任务成功，取消不成功。成功后故障仍继续返航、故障暴露、落地和维修。

恰好成功点故障：成功点优先，用户于2026-09-11确认（手册“before”措辞的本地解释，不声称原厂同刻调度已实测）。既有落地同刻规则保持：完整完成优先。案例使用5/6，新增任务默认1。

## 数据契约

任务结果：success_fraction、success_point、successful、success_at、success_phase、success_reason、successful_members；flight_status仍为原始物理终态。汇总任务提供success_rate、started_rate、successful_aircraft_sorties与原flight_rates，不把聚合均值时刻冒充某次真实时刻。

原生导出任务汇总CSV与逐轮任务明细CSV；后者按一次重复试验的一次编队任务一行（案例1000×9=9000行）。时刻使用仿真起点起算小时；成员以JSON数组保存。首轮事件日志有截断限制，全轮判定依赖未截断的任务明细。

升级不改变历史run的engine、snapshot或结果。历史缺失成功指标显示“未计算，请重跑”，不从完成率猜测FMSUC。新模型/结果格式5阻止旧软件误读。

## 限制

本版不实现部分编队、任务依赖、延迟起飞、任务期间替补、保障资源竞争、阶段独立故障倍率、原厂数值认证。时间类原厂指标在审计完成前仍保留本地名称，见METRIC_DICTIONARY.md。
