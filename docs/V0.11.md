# v0.11 采购与寿命报废

本次新增 M3 采购与报废闭环。项目概览可新建“采购与报废示例”，输入为合成演示数据。

## 建模

- 在“备件与供应 → 外部采购策略”按方案、地点、部件设置采购。任意层级均可配置；未配置则不能采购。
- 触发方式选择临界库存或指定周期，补至目标库存位置；采购交期为固定小时数，允许为零。
- 库存位置同时计入调运和采购的已申请未到货数量，扣除未满足需求。两种方式同时可用时按到货时间选择，调运不足部分可采购；交期相同优先调运。
- 已发运或已下单的数量不因后来出现更快来源而取消。已生成但未分配实物的调运缺口，可在采购满足自身触发条件时由采购承接。
- 在“装备组成 → 部件寿命报废限值”设置累计运行小时或修复性维修次数；可设其中一项或两项，任一到限即退出使用。
- 运行小时和维修次数终身累计，不随修复如新清零。只有实际完成修复性维修的部件计次；预防维修、拆装运输、父件因子件维修均不计次。完成第 N 次维修达到限值后立即报废。
- 飞行中运行小时到限，允许完成本次飞行，落地后换件，不能带着待报废件再次出动。换件沿用已有拆卸、安装、测试及资源配置；缺件等待调运或采购。
- 整件和内部部件可各自设限值。整件退出时其内部件随之退出，不模拟报废后拆解、回收或处置。
- 新采购部件到货时生成新实物身份；整件和内部件的运行小时、有效年龄、修复次数均为零。

## 查看结果

“调运与采购”可选择补货申请、调运批次、外部采购及库存；“维修与寿命”可选择工单、预防时钟、报废记录及实物寿命台账。界面显示首轮，导出 CSV 包含全部轮次和截断标识。说明继续按需查看。

## 兼容与范围

扩展格式为 11，可读取格式 1～10；保存后旧版程序不能读取新格式。用户原文件不会自动批量迁移；打开历史实验仍显示其原有结果。

外部供应不设业务数量上限，但保留仿真规模保护：每轮累计实物记录超过 200000 件时明确停止，避免无限内存增长。供应中断、运输容量、采购成本和报废后的处置不在本轮范围。

开发验收计划及证据见 `docs/superpowers/plans/2026-09-16-procurement-retirement.md` 与 `docs/VERIFICATION.md`。
