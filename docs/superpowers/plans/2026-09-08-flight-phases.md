# Flight Phase Implementation Plan

**Goal:** 使用原有MissionType.TFOUT/TFRET输入执行出航、任务区、返航三阶段，并按阶段计算中止返航时间。

**Architecture:** 编译器验证比例，仅飞行模式支持非零比例；FlightManager维护阶段、落地事件和阶段积分。故障使任务停止有效供给，但飞机直到落地才释放；健康部件在中止返航时继续暴露，落地后处理故障组件。原比例0模型保持即时返航。

**Tech Stack:** Python、SimPy、NumPy、PySide6、pytest、PyInstaller。

- [x] 编译输入及边界测试：各比例[0,1]、和≤1、零阶段、非飞行模式拒绝非零输入。
- [x] 阶段状态机：正常边界切换；OUT故障返航=已出航比例×计划返航；任务区故障=完整返航；BACK故障=剩余返航。末端落地边界优先，追加故障不延长已确定返航。
- [x] 故障与维修：返航占用飞机，不允许维修/准备/补位。返航健康部件继续故障，去重LRU落地后依次拆装送修；多故障维修为本版串行处理假设。单独列故障返航停机状态。
- [x] 指标和界面：出航/任务区/返航实际装备小时、中止返航装备小时、正常任务有效供给分列；输入字段中文标签；结果页显示阶段计划和实际均值。原MSUCPT成功点仍未实现。
- [x] 回归与案例：旧82项回归、阶段单测、维修不得早于落地、部件守恒；3小时、1/6+2/3+1/6案例1000次运行。
- [x] 发布v0.6.0桌面程序，保存原版备份，验证打包和项目，输出启动入口、报告、CSV和完整案例包。
