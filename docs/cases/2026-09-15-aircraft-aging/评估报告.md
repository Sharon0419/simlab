# M2 部件老化验收案例

日期：2026-09-15。合成案例，12架飞机、三天、每种修复方式1000轮，保留日历维修及飞行小时检查。四种叶子部件均采用形状2、尺度40运行小时、初始装机年龄20小时。

PERFECT 与 MINIMAL 各记录1576次已完成修复，平均每轮1.577次故障，任务成功率19.088889%。每轮48个实物部件，年龄变化与修复抹去的年龄守恒；两类计划维修工单、检查计时、实际飞行时间与部件总量复核通过。原v0.9.1案例1000轮数值及首轮事件相同。具体机器可读结果见 verification.json。

本短期案例两种策略的任务指标相同，不能从本案例声称任何一种更优。另有固定风险预算、持续重复运行的解析测试：首次均在40小时故障，修复如新第二次在130小时故障，最小修复第二次在约78.062485小时故障，证明维修年龄方式影响后续寿命。

同目录 PERFECT/MINIMAL.simproj 为完整输入及历史结果。对应 ages.csv 为全轮实物年龄，events.csv 为全轮故障修复记录。首轮源码、保存结果与可执行程序一致性由 release-verification.json 独立记录。

复现：在项目根目录运行 `.venv/Scripts/python.exe tools/run_aircraft_aging_case.py`；验证包可追加 `--verify-only --exe dist/SimLab/SimLab.exe`。这些验证不构成真实系统校准或原厂等价认证。
