# SimLab 0.2 Implementation Plan

**Goal:** 在本地 Git 保留 0.1 基线，交付可执行的任务需求日历、维修班次和任务缺口分析。

**Architecture:** 保留原字典和项目格式。新增 operations.py 编译受限的原字段子集，missions.py 负责需求窗口与设备分配；engine.py 连接按任务累计的故障时钟和资源开班门控。无 Operations 的旧模型保持原连续使用语义。

**Tech Stack:** Python、SimPy、NumPy、Qt、SQLite、pytest、PyInstaller。

当前环境无 superpowers 执行技能，按用户授权在本会话执行。

- [x] 执行原 14 项测试；创建本地基线提交与 v0.1.0 标签，切换 codex/v0.2-missions-calendars。
- [x] tests/test_operations.py：先建立可手算案例，覆盖无故障需求、不足、重叠竞争、同刻交接、待命不故障、故障补位、班内开始与跨班完成、关闭期阻止新作业、输入拒绝和项目往返。
- [x] simlab/operations.py：校验固定单系统任务、单层计划、单次启动；班次使用显式绝对时间窗口。拒绝未实现的优先级、随机持续时间、递归剖面和最低数量差异。

验收命令：`.venv/Scripts/python.exe -m pytest -q`；设置 QT_QPA_PLATFORM=offscreen 后执行 `main.py --smoke build/qa-v02-source` 和 `dist/SimLab/SimLab.exe --smoke build/qa-v02-package`。所有进程必须退出 0、检查 passed。

约定：任务窗口是本引擎的固定需求窗口子集，不宣称原厂任务成功判定等价。任务中每台设备全强度使用（UTIL=1）；待命不累计运行故障。班外不启动维修，已开始允许加班完成。采样只显示，积分决定指标。结束于仿真终点的任务纳入完整窗口统计，跨终点的计划拒绝并提示。
