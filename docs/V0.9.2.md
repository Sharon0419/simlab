# v0.9.2：部件老化与维修年龄

本版完成 M2 的部件寿命与修后年龄功能；发布验证及安装状态见 VERIFICATION.md。

## 使用

在“模型数据 → 装备组成 → 部件老化与修复”添加叶子部件。带 SRU 的 LRU 不单独老化，年龄属于实际子件。

| 输入 | 说明 |
| --- | --- |
| 寿命形状参数 | 1 至 10，默认 1。1 为恒定故障风险，大于 1 为风险随运行年龄增长 |
| 寿命尺度小时 | 必须为正且至少百万分之一小时；尺度不等于平均寿命 |
| 初始有效运行年龄 | 同类初始装机部件共用，默认 0；初始库存为新件 |
| 修复年龄方式 | 默认修复如新；可选最小修复 |

配置本表的部件必须将旧故障率 FRT 设为 0。未配置的部件继续使用旧指数故障模型。应用系数和结构环境系数改变故障风险；使用率改变运行年龄累计速度。

修复如新在实际维修完成时清零被修叶子的有效年龄；最小修复保留年龄。两者都保留终身运行小时。换装备件时实物年龄一起流转，总成内其他健康子件不清零。飞行小时检查和日历计划维修不改变年龄。

运行时累计年龄，待命、准备、维修、运输、库存暂停。飞行返航的健康部件继续运行，已经故障的部件停止累计。终身运行小时包含初始有效年龄和本轮新增运行小时；未额外输入历史被修复抹去的年龄。

## 查看与导出

“结果分析 → 部件老化”显示首轮实物年龄及故障/维修年龄记录。两个导出按钮输出全部轮次，包含种子、模型哈希、引擎版本和轮次。每轮实例及事件分别最多保留 10000 条；界面和 CSV 明确标记截断。

独立扩展格式升级为 9，支持读取 1–8；旧软件拒绝新格式。旧实验结果不补算年龄，配置后需要重新运行。当前支持 29 表、235 字段，独立扩展 7 表、36 字段，原始字典保持 133 表、891 字段。
