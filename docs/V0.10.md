# v0.10.0 三级供应与维修方式

本版在显式选择 M3 执行模式后，启用三级供应、临界库存或周期调运、原位/换件维修及部件预防性维修。未选择 M3 的既有项目继续使用旧执行路径。输入为 SimLab 独立扩展，不代表原厂等价认证。

## 直接体验

在“项目概览”点击“新建三级供应与维修方式示例”，进入“仿真实验”校验并运行。示例使用4架飞机、中心/区域/基地三级地点、9个双机窗口；参数为合成假设。结果分析新增“供应调运”和“维修方式”两页，可切换明细、导出全部轮次 CSV。界面显示首轮，导出含轮次、模型哈希、随机种子和引擎版本。

## 配置顺序

1. `SimLabExecution.MODE=M3`；`StationStructure` 定义最高三级地点关系，旧隐式运输时间设0。
2. `SimLabSupplyRoute` 按部件配置供货方向与固定运输小时。中心直达基地必须有独立路线；不从层级关系推导直达路线。
3. `SimLabSupplyPolicy` 按方案、地点、部件选择 `THRESHOLD` 或 `PERIODIC`。前者在库存位置不高于临界值时补至目标；后者按首次时刻和间隔检查。两者不能对同一配置同时启用。
4. `SimLabRepairLocation` 指定拆下件修理地点，`SimLabServiceRoute` 单独配置送修方向。供货路线不自动充当送修路线。
5. `SimLabMaintenanceRule` 按母件、部件、地点和维修类别选择原位、换件或混合。混合的 `REPLACE_P` 为0～1换件概率，修复性和预防性分别配置。
6. `SimLabMaintenanceStep` 配置诊断、原位维修、拆卸、安装、测试工序；`SimLabOffItemService` 配置拆下件的诊断、修理及测试。每道工序可指定资源任务。
7. `SimLabItemPreventive` 只为叶件配置日历或有效运行小时周期、初始累计小时。带子件总成不允许以父件整修绕过子件。

## 调运口径

库存位置 = 未预留的可用库存 + 已申请但未收到的数量 − 未满足需求。在途已包含在未到货中，只计一次。申请可拆分从多来源发货，优先时长最短且有货的显式路线，时长相同按路线编号稳定排序。所有来源缺货时保留申请，到货或修复入库后重新分配。周期调运已产生的申请在两个触发点之间仍可发货。

三级缺货向上传递时只由一个来源记录缺口，替代来源满足后撤销该缺口；已经创建的上级补货订单保留，因此短期库存可能高于目标。运输第一版无容量上限和运输资源排队。没有采购、报废、供应中断或横向调拨。

## 维修口径

每张工单只抽一次混合维修方式；没有备件会等待，不会重新抽签或改做原位维修。换件后飞机完成测试及再次出动准备即可恢复，不必等待拆下件修理。修复件进入指定地点共享库，不绑定原使用地点。

预防性维修按实物跟踪；运行时钟在非运行期间暂停，日历时钟在库存和运输中继续。到期库存隔离，不能继续发给飞机。空中到期先完成落地再维修，不额外触发中止。同一实物同一时刻只保留一项待执行预防作业。修复如新可覆盖未开始的同件预防维修，最小修复不能覆盖；普通飞行小时检查不重置部件年龄。

## 兼容与迁移

项目扩展格式为10，可读取格式1～9；旧版不能读取格式10。旧结果仍能查看，不会伪造 M3 明细。迁移入口先显示字段来源、差异和新增库存策略假设，确认后创建独立项目副本；当前只自动迁移支持的叶件模型，复杂总成及不能保持随机拆装相关性的输入会明确拒绝，需按新表配置。

明细最多保留每轮每类10000条，超限时界面与 CSV 明确标记；汇总计数保留完整值。验证进度见 [验证记录](VERIFICATION.md)。
