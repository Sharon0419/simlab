v0.7现已区分成功率、完整完成率和时间满足率，见[V0.7.md](V0.7.md)与[指标字典](METRIC_DICTIONARY.md)。

已确认：半小时为一次完整准备；每天首波健康地面飞机假定已提前准备好。故障机不恢复，未完准备由首波假设接续时单独记账、释放资源。准点不足取消，不增加延迟起飞DTIM。

多作业拆分前需要讨论：作业名称与各自分钟数、串行/并行和前置关系、各工种/设备数量、是否共用保障组、能否同时在同一飞机上作业。建议先做固定顺序工序，再考虑并行，避免把总时长错误地相加或重复计算。

原路线图中的v0.9计划维修仍保留；多作业拆分是否先作为v0.8后续迭代，需要用户确认排期。原厂数值对照仍需独立验证。
