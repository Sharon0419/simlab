# 本机保障仿真工作台 Implementation Plan

**Goal:** 制作可运行的 Windows 本机软件，按本机 SIMLOX 数据字典建立模型，支持项目文件交换和真实离散事件计算。

**Architecture:** Qt 桌面界面调用独立的 Python 项目与模型模块；QProcess 子进程读取模型快照并执行仿真。项目使用 SQLite，交换包使用带校验清单的 ZIP。输入表全量保留，运行前检查当前引擎的支持范围。

**Tech Stack:** Python 3.10、PySide6 Essentials、SimPy、NumPy、SQLite、pytest、PyInstaller。

按用户已授权的制作请求在当前会话内执行。当前环境没有 executing-plans / subagent-driven-development 技能；使用以下明确边界逐项实现和验证。

- [x] 提取本机 DatabaseDictionary_SIMLOX.txt 到 schema JSON，保持表名、列顺序、代码、类型、默认值、约束和关联；逐项验证 133 张表、891 字段与原文一致。
- [x] 实现 schema.py / validation.py：字段转换、必填、数值、枚举、组合键、跨表引用和结构循环校验。测试非法数值、重复键、悬空引用。
- [x] 实现 project.py：SQLite 原子保存、备份、完整/模型项目包、校验和、安全导入、新分支。测试往返、篡改、路径穿越和父版本追溯。
- [x] 实现 compiler.py / engine.py：明确支持的一层串联 LRU、连续使用率、指数故障、有限库存、运输、维修资源、重复试验。拒绝未实现的非默认参数。测试可复现、零故障、守恒和解析基准。
- [x] 实现 main.py / ui：中文桌面布局、全量表编辑、字段说明、CSV 交换、运行进度、取消、结果对比与图表。Qt 自动化完整走通保存、打开、运行和结果持久化。
- [x] 添加启动与打包脚本，生成便携 Windows 可执行版本、示例项目和说明文档；运行源码与打包版本的 smoke 检查，保存截图。

关键契约：Project={id,revision,parent_revision,name,tables,runs}; 每次计算读取冻结 tables，结果记录 SHA256、引擎与依赖版本和种子。字典支持不等于仿真功能支持；原厂 .sxi 二进制格式不在本版兼容承诺内。
